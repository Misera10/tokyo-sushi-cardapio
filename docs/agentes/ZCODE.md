# Zcode

Cole o conteudo de `docs/agentes/INSTRUCOES-PARA-COLAR-NOS-AGENTES.md` nas instrucoes fixas do Zcode.

Ao abrir um projeto, peça:

```txt
Antes de mexer no codigo, leia CONTEXT.md, AGENTS.md e a spec em specs/.
Siga a base Spec-Driven do Estudio Fernandes.
```

## Morph

Quando Morph estiver configurado no Zcode, use como acelerador:

- Compact para reduzir contexto longo.
- WarpGrep para buscar na codebase antes de ler muitos arquivos.
- Fast Models para codigo, revisao e auditoria controlada.

Nao substitua provedores existentes sem backup. Nao salve `MORPH_API_KEY` no projeto.
