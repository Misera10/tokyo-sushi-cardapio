## Morph

Use Morph apenas como ferramenta de harness quando fizer sentido:

- Compact para resumir contexto grande.
- WarpGrep para busca de codebase.
- Fast Models para testes de modelos OpenAI-compatible.

Nao instalar SDK Morph no site publico sem spec. Nao salvar `MORPH_API_KEY` no repositorio.
