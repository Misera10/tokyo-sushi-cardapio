Problema atual:
O Tokyo Print v0.3.18 foi instalado, mas quando um cliente faz um pedido pelo cardápio, o pedido chega ao Admin e não é impresso automaticamente. A impressão de teste precisa ser verificada separadamente. Não altere dados de pedidos, produtos, financeiro ou configurações do Supabase sem evidência e sem explicar antes.

Fluxo esperado:
1. Cliente monta o pedido no cardápio.
2. O pedido é criado no Supabase pela função tks_create_order.
3. O Admin detecta o novo pedido em tks_orders.
4. Se operation_settings.printOnNewOrder estiver ativo, o Admin chama:
   POST http://127.0.0.1:4242/v1/print-order
5. O Tokyo Print recebe o pedido, coloca na fila e envia para a impressora padrão do Windows.
