# Workflow: Post Instagram

Use para criar posts, carrosseis, prompts de imagem e legendas.

## Passos

1. Definir objetivo: autoridade, venda, prova, bastidor, educacao ou oferta.
2. Definir mensagem unica do post.
3. Criar arte com identidade do Estudio Fernandes ou do cliente.
4. Garantir texto grande e legivel no celular.
5. Usar logo oficial quando houver.
6. Criar legenda com gancho, desenvolvimento, CTA e hashtags.
7. Salvar prompt vencedor em `harness/memory/prompts-instagram.md`.

## Guardrails

- Nao usar logo inventada quando logo oficial foi fornecida.
- Nao colocar texto pequeno demais na arte.
- Nao misturar muitas mensagens no mesmo post.
- Nao usar visual generico se existir identidade definida.
