# Workflow: Auditoria Visual Mobile

Use quando o usuario apontar problema visual, escuro demais, texto pequeno, sobreposicao ou confusao.

## Passos

1. Identificar a secao exata pelo print ou URL.
2. Preservar copy aprovada se o pedido for apenas visual.
3. Corrigir contraste, tamanho, espacamento e hierarquia.
4. Verificar mobile primeiro.
5. Rodar lint/build quando houver codigo.
6. Publicar se o site ja estiver em producao.

## Checks

- Texto legivel sem zoom.
- Elementos nao se sobrepoem.
- Fundo nao engole o conteudo.
- Botoes sao tocaveis.
- Visual segue a identidade do projeto.
