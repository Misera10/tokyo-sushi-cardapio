# Workflow: Novo Projeto

Use quando iniciar qualquer projeto novo.

## Entrada

- Nome do projeto.
- Tipo: landing page, site, sistema, dashboard, automacao, post, outro.
- Objetivo comercial.
- Publico e canal de conversao.

## Passos

1. Aplicar o kit Spec-Driven, se ainda nao existir.
2. Preencher `CONTEXT.md` com termos especificos do projeto.
3. Criar spec em `specs/nome-do-projeto/`.
4. Completar briefing, user stories, design tecnico, tarefas e checklist.
5. Selecionar skills necessarias.
6. Implementar a primeira fatia vertical.
7. Rodar checks de qualidade.
8. Registrar aprendizados.

## Saida Esperada

- Projeto com spec preenchida.
- Tarefas claras.
- Agente autorizado a implementar apenas o que esta especificado.
