# Guardrails: Visual

- Nao entregar texto pequeno no celular.
- Nao entregar fundo escuro sem contraste.
- Nao criar cards dentro de cards sem necessidade.
- Nao usar paleta generica roxo/azul se a marca tiver direcao propria.
- Nao usar mockup pequeno como explicacao principal.
- Nao mudar copy aprovada quando o pedido for apenas visual.
- Todo CTA precisa parecer clicavel e ter alvo confortavel.
- Primeira tela deve comunicar marca, oferta e acao.
