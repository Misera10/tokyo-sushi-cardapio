# Tool: Firecrawl

Repositorio: https://github.com/mendableai/firecrawl

## Quando Usar

- Extrair conteudo de site atual do cliente.
- Coletar referencias de concorrentes.
- Transformar paginas em Markdown/JSON para briefing, SEO e copy.
- Mapear paginas publicas antes de redesign.

## Como Usar No Fluxo

1. Defina o objetivo da coleta na spec.
2. Extraia apenas paginas relevantes.
3. Salve o resumo util em `specs/*/01-briefing.md`.
4. Use dados coletados para copy, SEO, servicos, FAQ e estrutura.
5. Nao copie texto do concorrente; use como referencia de posicionamento.

## Criterios

- Conteudo coletado tem fonte clara.
- Dados sensiveis nao sao raspados.
- Copy final e original e adequada ao cliente.

## Nao Usar Para

- Burlar login, paywall, termos de uso ou rate limit agressivo.
- Alimentar o agente com volume enorme sem curadoria.
