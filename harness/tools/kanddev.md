# Tool: Kanddev

Repositorio: https://github.com/kanddev/kanddev

## Quando Usar

- Orquestrar frota de agentes em paralelo.
- Projetos grandes com muitas tarefas independentes.
- Visualizar diffs por worktree antes de integrar.

## Como Usar No Fluxo

1. Quebre a spec em tarefas Kanban.
2. Use uma worktree por agente.
3. Revise diffs antes de juntar.
4. Rode checks completos no branch consolidado.

## Criterios

- Cada card tem criterio de aceite.
- Nenhum agente edita fora do escopo.
- Merge final e revisado.

## Nao Usar Para

- Site simples, landing page pequena ou ajuste visual pontual.
- Substituir gestao clara de spec e tarefas.
