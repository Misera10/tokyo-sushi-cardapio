# Tool: Img23JS

Repositorio: https://github.com/img23js/img23js

## Quando Usar

- Recriar objeto visual como modelo procedural 3D.
- Gerar asset Three.js leve baseado em imagem.
- Prototipar elementos visuais sem depender de imagem pesada.

## Como Usar No Fluxo

1. Use quando o pedido for visual/3D e houver referencia clara.
2. Gere resultado procedural com primitivas.
3. Valide em desktop e mobile.
4. Capture screenshot para conferir enquadramento.

## Criterios

- Asset carrega rapido.
- Cena nao fica em branco.
- Visual combina com a marca.

## Nao Usar Para

- Logo final de marca sem revisao visual humana.
- Interfaces comuns que ficam melhores com HTML/CSS.
