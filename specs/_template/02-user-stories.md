# User Stories

## Historia 1

Como usuario, quero entender a oferta para decidir se sigo para o proximo passo.

### Criterios de Aceite

- Dado que acesso pelo celular, quando vejo a primeira tela, entao entendo a oferta sem dar zoom.
- Dado que quero agir, quando clico no CTA principal, entao sou levado ao canal correto com contexto.
