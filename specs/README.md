# Specs

Esta pasta guarda o contrato vivo do projeto. Toda mudanca relevante deve nascer de uma spec ou atualizar a spec existente antes de mexer no codigo.

## Fluxo Padrao

1. Especificar: briefing, objetivo comercial, usuario, acao principal e criterios de aceite.
2. Projetar: design visual, design tecnico, rotas, dados, integracoes e restricoes.
3. Decompor: tarefas pequenas ligadas as historias.
4. Executar: implementar uma fatia por vez.
5. Auditar: comparar codigo, layout e comportamento contra a spec.
6. Aprender: registrar decisoes, problemas e padroes reutilizaveis.
